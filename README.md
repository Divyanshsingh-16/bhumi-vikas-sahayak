## The user
A building-permission clerk at Bhopal Municipal Corporation answering a citizen at the counter in under a minute.

## What it does
Ask in plain English or Hindi — by typing or 🎤 mic (browser speech recognition, hi-IN + en-IN, auto-copies to chat). Get a short deterministic headline in the same language (numbers from code, perfect Hindi even offline) with the Rule number (+ sub-clause), PDF pages, exact quote, and 🟢🟡🔴 confidence. Extras for the counter: kiosk large-text mode, Case-file tab (road/plot/built-up inputs → front + rear + fee in one click), SVG plot diagram, 1-page print slip (PDF/text), PDF page evidence viewer, 🔊 listen button on every answer, thumbs feedback + daily query log, conflict guard (Rule 103 precedence), in-app accuracy dashboard. **Voice-persona:** SVG avatar face (talking/listening animation), hands-free voice loop in Bot tab (bolo → Sahayak bolkar jawab de → mic khud wapas, auto same-language HI/EN), auto-speak toggles for bot + chat, one-shot mic-to-text bridge. **Visual:** 🤖 Sahayak Bot tab (guided slot-filling, quick-reply plot sizes, HI+EN), 🏙️ 3D View tab (Three.js plot + building, drag-rotate, green/red violation highlighting, proposed-vs-required checker, 2D fallback offline, real Bhopal OpenStreetMap). **UI:** BMC-green theme, tricolor hero + stat chips, global EN/हिंदी toggle, card-style answers with rule chips + confidence pills, kiosk high-contrast mode, first-visit 3-step strip, fee breakdown table (slab + high-rise + revalidation), application journey stepper with deemed flags. **New:** 📜 Amendment + Forms tab (28-08-2026 Rule 2(5)(c) explainer EN+HI + form/checklist router for development/building/alteration/revalidation with fee hints), deterministic headlines for documents/sign/plan-change/deemed-sanction/plan-precedence, follow-up context (short follow-ups inherit the last question), ▶️ 1-click guided demo, Officer tab (counter-log analytics: queries, top rules, not-found rate). Every screen shows the version stamp (rules upto 06-03-2025 + 28-08-2026 patch note).

## How to run
1. `cp .env.example .env` and add `ANTHROPIC_API_KEY` (optional — works offline without it)
2. `python3 -m pip install -r requirements.txt`
3. `python3 chunk_rules.py` (builds sub-clause index; `data/chunks.jsonl` is prebuilt)
4. `python3 extract_pdf_pages.py` (optional — enables in-app PDF evidence from the official EN PDF)
5. `streamlit run app.py`

Or with Docker: `docker build -t bhumi-sahayak . && docker run -p 8501:8501 --env-file .env bhumi-sahayak`

## What works, what does not
- Works: chat in EN/HI over all 106 rules (883 sub-clause chunks); rule + subref + pages + verbatim quote; deterministic front/rear/side setback (R56), electric (R52), farmhouse (R17), validity (R23), fee slabs + application/revalidation/high-rise fees (R21), lift rule (R83), FAR table (R61), documents (R14/16), sign (R18) + competence table (R26(9): Architect/Engineer/Supervisor limits), plan-change (R24/19), deemed sanction (R28) + occupancy-deemed (R31) + inspection timelines (R33), plan precedence (R103), instant approval ≤186 sqm (R12-A), standard plans ≤300 sqm (R21(4)), room minimums (R69-71), plantation/RWH (R67/81), projections/walls (R58/78), high-rise bands (R42), deadline math (R23/28/31/33), route wizard (plot-size ladder), layout access (R38), site buffers (R50), septic (R79), staircase (R80), hectare conversion; citizen screen, full case PDF, FAQ instant, WhatsApp share, saved cases, digest; form/checklist router; amendment explainer; follow-up context; demo mode; officer analytics; not-found on property-tax / land-rate / stamp-duty / water-bill; offline extractive fallback; print slips; plot diagram; PDF evidence for fee/electric/residential pages.
- Does not work yet: 28-08-2026 amendment text is a warning banner + verdict (amendment PDF not in pack); Hindi PDF not parsed (old font — Hindi support is via keyword map + templates + UI); voice STT needs internet (Chrome), TTS + text work offline; embeddings rerank is opt-in via `USE_EMBEDDINGS=1` + `sentence-transformers`.

## Accuracy
- `python3 eval/run_17.py` (official 17): **17/17 top-3**, incl. 2/2 correctly NOT-FOUND.
- `python3 eval/run_v2.py` (17 + 63 edge/Hindi/paraphrase/source-grounded = 80): **80/80 top-3, 78/80 top-1**.
- Table spot-checks vs EN PDF: front 9m→3.0 / 10m→3.6 / 20m→6.0 (R56 p.77); rear 40→Nil / 150→1.5 / 225→2.5 / 300→3.0 (R56 p.78); low-voltage 2.5V/1.2H, >33kV 15m corridor (R52 p.69); farmhouse 0.40ha/FAR 0.10/7.5m (R17 p.34); validity 3yr+2×1yr (R23 p.41); lift >12.5m (R83 p.95).
- See `eval/results.csv`, `eval/results_v2.csv`.
